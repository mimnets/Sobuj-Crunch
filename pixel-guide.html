Meta Pixel সেটআপ: ধাপে ধাপে

ল্যান্ডিং পেজে কে ঢুকছে, কে প্যাকেজ বাছছে, কে অর্ডার দিচ্ছে, Facebook যেন তা জানতে পারে। তাহলে অ্যাড ঠিক সেই ধরনের মানুষদের দেখানো হবে, যারা আসলে কেনে।

১ Pixel তৈরি২ ID বসানো৩ পেজ লাইভ৪ টেস্ট৫ ডোমেইন যাচাই৬ অ্যাড চালু
আগে জেনে রাখুন: Meta মাঝে মাঝে মেনুর নাম বদলায়। এখন "Pixel"-কে অনেক জায়গায় "Dataset" বলা হয়, দুটো একই জিনিস। কোনো বাটন হুবহু না পেলে কাছাকাছি নামের অপশন খুঁজুন।

০যা যা আগে লাগবে

  • সবুজ ক্রাঞ্চের একটি Facebook Page
  • Meta Business Portfolio (আগের নাম Business Manager): business.facebook.com-এ গিয়ে তৈরি করুন
  • একটি Ad Account, সাথে পেমেন্ট মেথড (ডুয়াল-কারেন্সি কার্ড বা অ্যাড এজেন্সি)
  • লাইভ ওয়েবসাইট: নিজের ডোমেইনে আপলোড করা ল্যান্ডিং পেজ, যেমন sobujcrunch.com। Claude-এর প্রিভিউ লিংকে Pixel কাজ করবে না।

১Pixel (Dataset) তৈরি করুন

  1. Events Manager খুলুন
  2. বাম পাশে Connect data sources (বা সবুজ + চিহ্ন) চাপুন
  3. Web বেছে নিয়ে Connect চাপুন
  4. নাম দিন: Sobuj Crunch Pixel → Create
  5. ওয়েবসাইটের ঠিকানা চাইলে আপনার ডোমেইন দিন
  6. ইনস্টলের অপশন এলে Install code manually বেছে নিন
  7. স্ক্রিনে বা Dataset-এর Settings-এ একটি ১৫-১৬ সংখ্যার নম্বর দেখাবে। এটাই আপনার Pixel ID। কপি করে রাখুন।
পুরো কোড কপি করার দরকার নেই। আমাদের পেজে Pixel-এর কোড আগেই বসানো আছে, শুধু ID-টা লাগবে।

২ল্যান্ডিং পেজে ID বসান

index.html ফাইলটি যেকোনো টেক্সট এডিটরে (Notepad, VS Code) খুলুন। একদম উপরের দিকে এই লাইনটা পাবেন:

const META_PIXEL_ID = 'YOUR_PIXEL_ID';

শুধু YOUR_PIXEL_ID মুছে আপনার নম্বর বসান। উদ্ধৃতি চিহ্ন (') রেখে দিন:

const META_PIXEL_ID = '1234567890123456';
উপরের নম্বরটা উদাহরণ মাত্র। ID না বসানো পর্যন্ত পেজের Pixel কোড ইচ্ছা করেই বন্ধ থাকে, তাই ভুল ডেটা যাবে না।

৩পেজ লাইভ করুন

index.html আর images ফোল্ডারটা আপনার হোস্টিংয়ে আপলোড করুন (cPanel File Manager, Netlify, Hostinger ইত্যাদি)। একই সাথে নিশ্চিত করুন:

  • WHATSAPP_NUMBER-এ আসল নম্বর বসানো হয়েছে (এখন ডামি 01712345678 আছে)
  • ফুটারে আসল ফোন নম্বর
  • সাইট https:// দিয়ে খোলে (SSL চালু)

৪Pixel কাজ করছে কিনা টেস্ট করুন

পেজে যে ইভেন্টগুলো আগে থেকেই সেট করা আছে:

ইভেন্টকখন ফায়ার হয়কী বোঝায়
PageViewপেজ খুললেইকতজন ভিজিটর এল
ViewContentদামের সেকশন পর্যন্ত স্ক্রল করলেআগ্রহী ভিজিটর
AddToCartকোনো প্যাকেজের "এটা নেব" চাপলেপ্যাকেজ বেছেছে (দামসহ)
InitiateCheckoutঅর্ডার ফর্মে প্রথম ক্লিক বা টাইপ করলেকেনার প্রক্রিয়া শুরু
Lead"অর্ডার কনফার্ম করুন" চাপলে (WhatsApp খোলার আগে)অর্ডার রিকোয়েস্ট এসেছে (মোট টাকাসহ)
  1. Chrome-এ Meta Pixel Helper এক্সটেনশন ইনস্টল করুন
  2. আপনার লাইভ পেজ খুলুন। এক্সটেনশনের আইকনে আপনার Pixel ID আর PageView দেখাবে।
  3. Events Manager → আপনার Dataset → Test events ট্যাবে সাইটের ঠিকানা দিয়ে Open website চাপুন
  4. খোলা পেজে স্ক্রল করুন, একটা প্যাকেজ বাছুন, ফর্ম পূরণ করে কনফার্ম চাপুন। Test events-এ উপরের ৫টি ইভেন্ট একে একে দেখা যাবে।
টেস্ট অর্ডারগুলো WhatsApp-এ আপনার কাছেই আসবে। পরে মুছে দিন, যাতে আসল অর্ডারের সাথে না মেশে।

৫ডোমেইন যাচাই (Domain verification)

  1. Business settings → Brand safety and suitability (বা Brand safety) → Domains → Add
  2. আপনার ডোমেইন লিখুন, যেমন sobujcrunch.com
  3. যাচাইয়ের দুটো সহজ উপায়:
    • Meta-tag: Meta যে <meta name="facebook-domain-verification" …> লাইনটা দেবে, সেটা index.html-এর <head>-এর ভেতরে বসিয়ে আবার আপলোড করুন
    • DNS TXT: ডোমেইন প্যানেলে (Namecheap, GoDaddy ইত্যাদি) Meta-র দেওয়া TXT রেকর্ড যোগ করুন
  4. Verify চাপুন
  5. Events Manager-এ ইভেন্ট সাজানোর (Aggregated Event Measurement) অপশন দেখালে Lead-কে সবার উপরে রাখুন

৬Pixel দিয়ে অ্যাড চালান

  1. Ads Manager → Create
  2. Objective: Leads (অথবা Sales)
  3. Conversion location: Website, Dataset: Sobuj Crunch Pixel, Conversion event: Lead
  4. Audience: বয়স ২৪-৪৫; লোকেশন শুরুতে ঢাকা ও চট্টগ্রাম শহর; আগ্রহ যেমন parenting, healthy eating, fitness, snacks
  5. Placement: Advantage+ (অটোমেটিক) রাখুন
  6. বাজেট: দিনে ৳৫০০-১,০০০ দিয়ে শুরু করুন। প্রথম ৫-৭ দিন অ্যাড এডিট করবেন না, কারণ তখন Facebook শিখছে (learning phase)।
  7. Ad-এর লিংক: আপনার ল্যান্ডিং পেজ। মূল অফার দেখান ৩ প্যাক ৳১,০৯৯।
ইভেন্ট কম হলে: সপ্তাহে ~৫০টির কম Lead হলে Facebook ভালোভাবে শিখতে পারে না। শুরুতে Conversion event হিসেবে InitiateCheckout দিন, অর্ডার বাড়লে Lead-এ বদলান।

৭আসল বিক্রি আলাদা করে গুনুন

পেজের Lead মানে কেউ অর্ডার পাঠিয়েছেন। কিন্তু সব Lead ফোনে কনফার্ম বা ডেলিভারি হয় না। তাই একটা Google Sheet রাখুন:

তারিখনামমোবাইলপ্যাকেজটাকাকনফার্ম?ডেলিভারি?রিপিট?
২৫/১১……৩ প্যাক৳১,১৬৯হ্যাঁহ্যাঁনা

প্রতি সপ্তাহে হিসাব করুন: অ্যাড খরচ ÷ ডেলিভারি হওয়া অর্ডার = আসল খরচ প্রতি অর্ডার। প্ল্যান অনুযায়ী লক্ষ্য ≤ ৳২৫০।

পরে চাইলে এই শিট থেকে কনফার্ম হওয়া অর্ডারগুলো Offline events বা Conversions API দিয়ে Meta-তে "Purchase" হিসেবে পাঠানো যায়। তখন Facebook আরও নিখুঁতভাবে আসল ক্রেতা খুঁজবে। শুরুতে এটা জরুরি নয়।

৮প্রাইভেসি ও সমস্যা সমাধান

প্রাইভেসি নীতি: Pixel ব্যবহার করলে Meta-র নিয়ম অনুযায়ী সাইটে একটি প্রাইভেসি নোটিশ রাখা উচিত। তাতে লিখুন: আমরা অ্যাডের জন্য Meta Pixel ব্যবহার করি, আর অর্ডারের তথ্য শুধু ডেলিভারির জন্য রাখি। চাইলে আমি এটা লিখে ফুটারে লিংক করে দিতে পারি।
সমস্যাসমাধান
Pixel Helper-এ কিছু দেখাচ্ছে নাID ঠিকমতো বসেছে কিনা দেখুন (শুধু সংখ্যা, উদ্ধৃতির ভেতরে)। ফাইল আবার আপলোড করে ব্রাউজারে Ctrl+F5 চাপুন।
শুধু PageView আসছে, Lead আসছে নাফর্ম পুরো পূরণ করে কনফার্ম চাপুন। ভুল নম্বর বা অসম্পূর্ণ ঠিকানা থাকলে ফর্ম জমা হয় না, তাই Lead-ও যায় না।
Ad blocker থাকলে ইভেন্ট যায় নাএটা স্বাভাবিক, কিছু ভিজিটর মিস হবেই। আসল হিসাব Google Sheet থেকে নিন।
ডোমেইন যাচাই হচ্ছে নাmeta-tag ঠিক <head>-এর ভেতরে আছে কিনা দেখুন; DNS হলে ২৪ ঘণ্টা পর্যন্ত অপেক্ষা করুন।
